# Kutira Kushala 📱

Kutira Kushala is a smart Android-based business discovery application developed using Kotlin and Jetpack Compose. The app helps users showcase and explore local businesses through an interactive and modern user interface.

## Features ✨

- Business listing and showcase
- Add new business details
- Search functionality for businesses
- Category-based filtering
- Business analytics dashboard
- Detailed business information screen
- Bottom navigation for easy access
- Modern Material 3 UI design
- Dynamic state management using Jetpack Compose

## Tech Stack 🛠️

- Kotlin
- Jetpack Compose
- Android Studio
- Material 3
- Navigation Component
- State Management

## Project Structure 📂

- Home Screen
- Add Business Screen
- Analytics Screen
- Business Detail Screen

## App Description 📖

Kutira Kushala is designed to improve visibility for small and local businesses by providing a simple digital platform where businesses can be listed, discovered, and analyzed through category-based insights.
